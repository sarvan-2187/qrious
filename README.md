# Qrious - Quant-A-Thon Project

## Frontend Setup

To run the frontend, open a terminal and run the following commands:

```bash
cd frontend
npm install
npm run dev
```

## Backend Setup

To run the backend, open a new terminal and run the following commands:

```bash
cd backend
python -m venv venv
.\venv\Scripts\Activate
pip install -r requirements.txt
fastapi dev main.py
```
